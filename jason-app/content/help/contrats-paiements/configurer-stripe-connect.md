## Comment ça marche

Le voyageur paie par carte sur une page Stripe sécurisée. L'argent arrive **sur ton compte Stripe**, puis sur ton compte bancaire. L'app ne prend **aucune commission** : seuls les frais de Stripe s'appliquent.

## Les frais de Stripe

Pour une carte européenne standard : **1,5 % + 0,25 €** par paiement. C'est plus pour une carte premium ou émise hors d'Europe. La grille officielle est sur [stripe.com/fr/pricing](https://stripe.com/fr/pricing).

> Exemple : un loyer de 500 € payé avec une carte française standard te coûte 7,75 € de frais.

## Connecter ton compte

1. **Mon compte** → carte **Encaissements** → **Connecter mon compte Stripe**
2. Stripe te demande tes informations : identité, activité, IBAN de versement. Si tu n'as pas de compte Stripe, il est créé à ce moment-là
3. Tu reviens dans l'app : la carte indique **Compte connecté**

Stripe peut demander une pièce d'identité et vérifier ton compte avant les premiers versements.

## Ce que ça débloque

- Le choix **Stripe (en ligne)** comme moyen de paiement dans les contrats
- La **caution par empreinte bancaire** (formule Standard)

## Sans Stripe

Tu peux renseigner ton **IBAN** dans la même carte : il s'affiche dans le contrat et le voyageur paie par virement. Tu suis alors toi-même la réception du paiement.
