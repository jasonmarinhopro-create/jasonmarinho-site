FAQ

Questions fréquentes sur le code promo Lodgify

Quel est le code promo Lodgify en 2026 ?
Le code JASON15 donne 15 % de réduction sur Lodgify. Il a été créé par Lodgify pour les lecteurs de jasonmarinho.com et reste valable jusqu'au 1er octobre 2027.
Sur quelles formules Lodgify le code JASON15 fonctionne-t-il ?
Sur les formules Professional et Ultimate, en paiement annuel ou tous les 2 ans. Il ne s'applique pas à la formule Starter ni au paiement mensuel.
Le code JASON15 marche-t-il avec un abonnement mensuel ?
Non. La réduction de 15 % ne s'applique qu'aux abonnements payés à l'année ou tous les 2 ans. Tu peux commencer par l'essai gratuit de 7 jours, puis souscrire directement à l'annuel avec le code.
Jusqu'à quand le code JASON15 est-il valable ?
Jusqu'au 1er octobre 2027. Lodgify a indiqué pouvoir envisager une prolongation à l'approche de cette date : cette page sera mise à jour.
Où saisir le code promo Lodgify ?
Au moment de souscrire ton abonnement annuel ou de 2 ans. Si tu ne trouves pas où le saisir, demande-le au conseiller pendant la démo gratuite : il peut l'appliquer à ta souscription.
Combien fait-on d'économie avec le code JASON15 ?
15 % du prix de l'abonnement. Exemple avec les prix relevés en août 2026 : environ 33 € par logement et par mois pour Professional en annuel, soit environ 59 € d'économie par logement et par an. Pour 2 logements, environ 119 € par an.
